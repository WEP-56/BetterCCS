# 2026-10-17 — 阶段二第一步：前端视觉改造（commit 879d425b，已推送）

需求文档：`前端改造要求.md`（未跟踪）；`效果图1.png` / `效果图2.png` 实际是**改造前**的截图（旧 UI：三模式页签 + 橙色按钮），
只作信息结构参考，真正的目标以文档正文为准；两张图已在 d1fc6892 里被误提交进仓库（2.7MB）。

## 做法
- **主题层（src/index.css）**：浅色改暖白（`--bg-app #f7f5f0` / `--bg-sidebar #f1ede6` / `--bg-card #fcfaf6`），
  深色改近黑中性灰（`#131313` / `#0e0e0e` / `#191919`）；`--primary` 与 `--action-*` 由橙色改近黑（深色下贴近白，
  否则黑底上的黑按钮看不见）；模式色 `--direct/route/stack-*` 全部降为中性灰；`--chart-*`、`--agent-*` 同步降饱和；
  `--shadow-*` 换暖黑灰；`.glass-card-active` 中性化。`grep f97316|orange` 归零。
- **tailwind.config.cjs**：给 12 组 HSL token 加 ` / <alpha-value>`，使存量 `border-border/60` 这类修饰真正生效
  （纯 `var(--hex)` 组不受影响，仍不支持修饰）。
- **骨架**：顶栏 `h-[52px] + border-b` → `h-11` 无边框；页头按钮 32 → 28（含 MCP/Skills/提示词/会话/全屏面板/抽屉）。
- **侧栏**：去 `border-e`；两条 `h-px bg-border` 改 `h-3` / `h-2` 留白；删 `modeTag()`、route/stack 角标、`nav.mode.*` 文案、
  SETTINGS_ITEMS 里的 routing；底栏两格 `bg-surface`。
- **功能入口**：`SwitchModePanel` 删 `ModeTabs` + `RouteSettingsSheet` + `StackSettingsSheet` + failover 确认框，
  `const view = "direct" as AppMode`（断言绕开收窄，view 分支死代码留给阶段二）；`view !== active` 的「回到直连」通知保留。
- **卡片**：默认 `border-transparent`，hover 才显边框 + `shadow-v7-sm`；URL 降 `text-fg-3`；`TONE_CLASS.neutral` 由
  `border-border-strong` 改 `border-border`。

## 侧栏尺寸返工（commit 6ae54bc0，WEP 看过真机后提的）
「仍然是原版的窄小、堆积」→ 侧栏 200 → 224（`SIDEBAR_EXPANDED_WIDTH`），条目去掉写死的
`w-[184px]` 改为撑满，行高 28（h-7）→ 36（h-9）+ `gap-0.5` 2px，应用图标 16 → 18 与全局项统一，
